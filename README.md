# Multi-Modules App

This is a sample project demonstrating an Android multi-module architecture, built with Kotlin and Gradle.

The repository structure includes several modules (`module-a`, `module-b`, `module-c`, etc.) along with application modules like `app`, `app-demo`, and `wear-app`.

## Module Organization Refactor

To review the results of refactoring and moving the modules into new directories, please check out the **`modules-organization`** branch.
